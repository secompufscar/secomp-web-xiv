# Site da SECOMP UFSCar

O site oficial da SECOMP UFSCar foi desenvolvido pela equipe de TI da SECOMP para fornecer informações completas sobre o evento.

Ele oferece aos visitantes uma forma fácil de acompanhar o cronograma, conhecer os patrocinadores, esclarecer dúvidas frequentes no FAQ e acessar outras informações importantes. Para a organização, o site serve como uma vitrine do evento e como uma plataforma centralizada para divulgar notícias, novidades e conteúdos relevantes para participantes, palestrantes e parceiros.

<br>

## ✨ Funcionalidades

- Cronograma completo do evento
- Conteúdo disponível durante a semana
- Patrocinadores
- FAQ
- Contato
- Fotos dos eventos

<br>

## 📋 Requisitos

Antes de mais nada, certifique-se de ter os seguintes programas instalados:

[![git][git-logo]][git-url]
[![node][node-logo]][node-url]

<br>

## ⚙️ Guia de Execução

Clone o repositório

```sh
git clone https://github.com/secompufscar/secomp-web-xiv.git
```

<br>

Acesse a pasta clonada

```sh
cd ./secomp-web
```

<br>

Instale as dependências

```sh
npm install
```

<br>

Execute o programa localmente
```sh
npm run dev
```
